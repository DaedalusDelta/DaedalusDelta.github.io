Task: top-face pickup, lift, free carry, placement/release, and withdraw. Watch each whole route before deciding whether it looks plausible for the task. Plausible, reject, and uncertain are all valid; there are no expected labels or category quotas.

How to read the illustrations

These are geometric illustrations, not robot execution or validated motion timing. Video seconds refer only to viewing time. The moving dot and saved geometry show the route; phase colors and pickup/placement markers provide task context.

Phases: approach → descent / pickup → lift → carry → place / release → withdraw. A phase boundary or grasp/release marker does not establish a timed pause. Use the supporting image if you need a closer geometry view, and report any missing context.
